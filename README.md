# FunkyStats

[FunkyStats](https://fsm.vyaas.dev) is an FRC data analytics tool that uses FSM, the Funky Scoring Metric, to make highly accurate predictions of teams' in-match performance.

### Why FSM?

- Predicts a team's scoring capabilities to within fractions of a cycle
- Responsive to sudden improvements in robot performance
- Leans towards a team's better and later matches for a better estimate of their scoring capabilities
